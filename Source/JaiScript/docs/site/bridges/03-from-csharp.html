    From C#​

    Much of JaiScript's surface is familiar from C#: classes with : this(...) chaining, a required override, statics, accessor properties, try/catch/throw, arrow lambdas, namespaces, ?. and ??, and yield.

    The semantics underneath are C++'s. Three things to learn first:

    1. A class is a value, as a C# struct is: b = a copies the object. new Hero() makes the shared reference that every C# class is, a shared_ptr<Hero>.
    2. A class value is never null. Hero h = null; is a load error; a slot that can be empty is a shared_ptr<Hero> or a var.
    3. var is C#'s dynamic; auto is C#'s var.

    Ported side by side​

    Five small C# programs and their JaiScript ports. Each pair was run, with .NET 10 and on both JaiScript backends, and printed the output shown. A JaiScript function is declared above the top-level code that calls it.

    A class as a reference type​

    c#
    var party = new List<Hero> { new Hero("Ada", 30), new Hero("Brom", 22) };
Hero leader = party[0];                      // a second reference to Ada
leader.Hp -= 10;
foreach (var h in party) { h.Hp += 1; }
Hero? target = null;                         // a reference may be empty
target ??= party[1];
Heal(target, 5);
string same = leader == party[0] ? "one Ada" : "two Adas";
Console.WriteLine($"{party[0].Name} {party[0].Hp}, {party[1].Name} {party[1].Hp}, {same}");

static void Heal(Hero hero, int amount) { hero.Hp += amount; }

class Hero {
    public string Name;
    public int Hp;
    public Hero(string name, int hp) { Name = name; Hp = hp; }
}
    jaiscript
    class Hero {
    string name;
    int hp;
    Hero(string n, int h) { name = n; hp = h; }
}
void heal(shared_ptr<Hero> hero, int amount) { hero.hp += amount; }

array<shared_ptr<Hero>> party = [new Hero("Ada", 30), new Hero("Brom", 22)];
shared_ptr<Hero> leader = party[0];          // a second handle to Ada
leader.hp -= 10;
for (auto h : party) { h.hp += 1; }
shared_ptr<Hero> target = null;              // a handle may be empty
target ??= party[1];
heal(target, 5);
string same = leader == party[0] ? "one Ada" : "two Adas";
print(`${party[0].name} ${party[0].hp}, ${party[1].name} ${party[1].hp}, ${same}`);
    output
    Ada 21, Brom 28, one Ada
    • Every C# class variable is a reference. JaiScript spells that out: new Hero(...) makes a shared_ptr<Hero>, and leader, target and the elements are handles to it. Only a handle can be null, and == on two handles asks whether they are one object.
    • Without new and the handle type the same lines work on values that copy: a class is a value has that program.

    A LINQ pipeline​

    c#
    var units = new List<Unit> { new("ogre", 30), new("imp", 8), new("elf", 15) };
List<string> names = units.Where(u => u.Hp > 10).OrderBy(u => u.Hp).Select(u => u.Name).ToList();
int total = units.Sum(u => u.Hp);
Unit? giant = units.FirstOrDefault(u => u.Hp > 99);
units.Sort((a, b) => b.Hp.CompareTo(a.Hp));  // in place
units.RemoveAll(u => u.Hp < 10);
Console.WriteLine($"{string.Join(", ", names)} | {total} | {giant?.Name ?? "nobody"} | {units[0].Name} of {units.Count}");

record Unit(string Name, int Hp);
    jaiscript
    class Unit { string name; int hp; }

array<Unit> units = [Unit("ogre", 30), Unit("imp", 8), Unit("elf", 15)];
auto healthy = array::sort(array::filter(units, u => u.hp > 10), (a, b) => a.hp < b.hp);
array<string> names = array::map(healthy, u => u.name);
int total = units.reduce((sum, u) => sum + u.hp, 0);
var giant = units.find(u => u.hp > 99);
units.sort((a, b) => a.hp > b.hp);           // in place
units.remove_if(u => u.hp < 10);
print(`${names.join(", ")} | ${total} | ${giant?.name ?? "nobody"} | ${units[0].name} of ${units.size()}`);
    output
    elf, ogre | 53 | nobody | ogre of 2
    • The pipeline is the array:: functions, which return new arrays; units.sort and units.remove_if work in place.
    • A comparator answers "does a go first?" with a bool. find answers null when nothing matches. A class with no constructor fills its fields in order, as a positional record does.

    A dictionary​

    c#
    var stock = new Dictionary<string, int> { ["arrow"] = 20, ["potion"] = 3 };
stock["rope"] = 1;

    • m[k] for a missing key raises a run-time error, as the C# indexer throws. get(k, fallback) is GetValueOrDefault, and contains before m[k] replaces TryGetValue.
    • A map iterates in key order, as a SortedDictionary does.

    An abstract base and a list of them​

    c#
    var shapes = new List<Shape> { new Circle(1.0), new Rect(2.0, 3.5) };
double total = 0.0;
foreach (Shape s in shapes) {
    Console.WriteLine(s);
    total += s.Area();
}
Console.WriteLine($"total {total:F2}");

abstract class Shape {
    private readonly string label;
    protected Shape(string label) { this.label = label; }
    public abstract double Area();
    public virtual string Name() => "shape";
    public override string ToString() => $"{label} {Name()}, area {Area():F2}";
}
class Circle : Shape {
    private readonly double radius;
    public Circle(double r) : base("round") { radius = r; }
    public override double Area() => Math.PI * radius * radius;
    public override string Name() => "circle";
}
class Rect : Shape {
    private readonly double width, height;
    public Rect(double w, double h) : base("boxy") { width = w; height = h; }
    public override double Area() => width * height;
}
    jaiscript
    class Shape {
private:
    string label;
public:
    Shape(string l) { label = l; }
    float area() { throw "Shape.area is abstract"; }
    string name() { return "shape"; }
    string to_string() { return `${label} ${name()}, area ${area():.2f}`; }
}
class Circle : Shape {
private:
    float radius;
public:
    Circle(float r) : super("round") { radius = r; }
    float area() override { return math::PI * radius * radius; }
    string name() override { return "circle"; }
}
class Rect : Shape {
private:
    float width;
    float height;
public:
    Rect(float w, float h) : super("boxy") { width = w; height = h; }
    float area() override { return width * height; }
}

array<shared_ptr<Shape>> shapes = [new Circle(1.0), new Rect(2.0, 3.5)];
float total = 0.0;
for (auto s : shapes) {
    print(s);
    total += s.area();
}
print(`total ${total:.2f}`);
    output
    round circle, area 3.14
boxy shape, area 7.00
total 10.14
    • No abstract and no virtual: the base method throws, every method is virtual, and override is required. : base(...) is : super(...), and access is set by private: and public: sections.
    • to_string() is ToString(): print and ${...} call it.

    A custom exception and using​

    c#
    foreach (int slot in new[] { 1, 7 }) {
    try {
        Save(slot);
    } catch (SaveFailed e) {
        Console.WriteLine($"failed: {e.Message} (slot {e.Slot})");
    }
}

static void Save(int slot) {
    using var guard = new SlotLock(slot);
    if (slot > 3) { throw new SaveFailed(slot, "no such slot"); }
    Console.WriteLine($"saved {slot}");
}

class SaveFailed : Exception {
    public int Slot { get; }
    public SaveFailed(int slot, string why) : base(why) { Slot = slot; }
}
class SlotLock : IDisposable {
    private readonly int slot;
    public SlotLock(int slot) { this.slot = slot; Console.WriteLine($"lock {slot}"); }
    public void Dispose() { Console.WriteLine($"unlock {slot}"); }
}
    jaiscript
    class SaveFailed {
    int slot;
    string message;
}
class SlotLock {
private:
    int slot;
public:
    SlotLock(int s) { slot = s; print(`lock ${slot}`); }
    ~SlotLock() { print(`unlock ${slot}`); }
}

void save(int slot) {
    SlotLock guard(slot);
    if (slot > 3) { throw SaveFailed(slot, "no such slot"); }
    print(`saved ${slot}`);
}

for (int slot : [1, 7]) {
    try {
        save(slot);
    } catch (SaveFailed e) {
        print(`failed: ${e.message} (slot ${e.slot})`);
    }
}
    output
    lock 1
saved 1
unlock 1
lock 7
unlock 7
failed: no such slot (slot 7)
    • Any value can be thrown, so SaveFailed extends nothing, and catch (SaveFailed e) selects by type.
    • using and IDisposable become a destructor: guard is a value, and ~SlotLock() runs when save ends, by return or by throw.

    C# prints its bools capitalized and throws only an Exception, so its program has no third line.

    The is-a test. x instanceof Hero is true for a Hero or a subclass and false for anything else, a value that is no object included. After it, cast<Hero&>(x) cannot fail; as stays the cast, which raises where C# would give null. A typed catch (Hero h) takes a Hero or a subclass the same way.

    Watch out​

    A class is a value, and so is a list of them​

    Assignment, a by-value parameter and a by-value return copy the whole object. An array<Unit> holds the units themselves, so a loop variable without & is a copy. & is C#'s ref, without the keyword at the call. An array of handles behaves like a C# List<Unit>. Value Semantics & References is the chapter on this.

    c#
    Unit a = new Unit();
Unit b = a;                                  // a second reference to one Unit
b.Hp = 50;
Hit(a);
Console.WriteLine($"{a.Hp} {b.Hp}");

var units = new List<Unit> { new Unit(), new Unit() };
foreach (var u in units) { u.Hp -= 5; }      // u refers to the element
Console.WriteLine(units[0].Hp);

static void Hit(Unit u) { u.Hp -= 1; Console.WriteLine($"inside: {u.Hp}"); }   // the caller's Unit

class Unit { public int Hp = 10; }
    output
    inside: 49
49 49
5
    jaiscript
    class Unit { int hp = 10; }
Unit a;
Unit b = a;                                  // a copy
b.hp = 50;
void hit(Unit u) { u.hp -= 1; print("inside: ", u.hp); }   // gets a copy
void hit_ref(Unit& u) { u.hp -= 1; }                        // like ref Unit
hit(a);
hit_ref(a);
print(a.hp, " ", b.hp);

array<Unit> units = [Unit(), Unit()];
for (auto& u : units) { u.hp -= 5; }         // u is the element
array<shared_ptr<Unit>> handles = [new Unit()];
for (auto h : handles) { h.hp = 1; }         // a copy of a handle shares the object
print(units[0].hp, " ", handles[0].hp);

5 1

    In C#, a, b and the parameter reach one Unit, so every number moves together; JaiScript copies at b = a and at the call.

    var is dynamic; auto is C#'s var​

    A var takes anything for its whole life. An auto takes its type from the initializer and keeps it: auto n = 5; n = "text"; is the load error cannot assign 'string' to 'n' declared 'int'.

    Integers are 64-bit and checked​

    2147483647 + 1 is 2147483648. Overflow at 263 raises Integer overflow in '+', as if every block were checked.
