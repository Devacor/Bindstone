Language Bridges

Three pages for programmers who already know another language. Each one sets that language beside JaiScript idiom by idiom, then lists the places where a habit from it gets a different answer, each with a sample that shows what JaiScript does, and ends with a complete program written the way that audience would write it. Every code sample was executed on both backends (tree-walking interpreter and bytecode VM); the output shown beneath each example is the real, verified output.

Run a sample by saving it as try.jai and running jaiscript try.jai with the standalone runner (Hello & Basics has the two-minute setup). The static checker is on, in strict mode, by default, so a typed mistake it can see stops the load before anything runs.

After a bridge, the Language Guide covers every rule in depth, starting from the same place each bridge points to first: Value Semantics & References.

  1. From JavaScript

    var, function, template strings and ?. carry over, with let, arrow functions, ??, do ... while and the array helpers (map, reduce, find, ...). Assignment copies arrays and objects, == compares contents and never converts, 7 / 2 is 3, lambdas name what they capture.

  2. From C++

    Value classes, references, destructors, operators and capture lists mean what they mean in C++. No pointers or templates, a narrow const; a defined evaluation order, checked overflow, no slicing, and a switch that never falls through.

  3. From C#

    Classes, override, statics and yield look familiar, but a class is a value type: new makes the shared reference. var is dynamic and auto is C#'s var; properties are accessor methods, and coroutines replace async.
