Hello & Basics​

JaiScript is a C++-flavored embedded scripting language: snake_case, hot-reloadable, zero static state, and shipped with two interchangeable backends (a tree-walking interpreter and a bytecode VM) that are kept at full test parity. Every example in these docs was executed on both backends; unless a divergence is called out, the output shown is identical on each.

Running a script from C++​

C++
#include <jaiscript/core/engine.hpp>
#include <jaiscript/stdlib/stdlib.hpp>

auto eng = jai::engine::make();                 // shared_ptr<engine>
// eng->set_backend(jai::backend_type::vm);     // optional: bytecode VM (before first execute)
jai::stdlib::register_all(eng);                 // print, format, to_string, type_of, to_json, ...
jai::script_value r = eng->execute("2 + 2");
int v = r.as_int();                             // 4

Two things to know from the start:

  1. **The last expression's value is the result of execute().** No return needed at top level.
  2. set_backend() must be called before the first execute() (forbidden after).

Values and literals​

jaiscript
auto i = 42;            // integer (64-bit)
auto f = 3.14;          // float (double)
auto s = "hello";       // string
auto c = 'x';           // char
auto b = true;          // bool
auto n = null;          // null
print(type_of(i), " ", type_of(f), " ", type_of(s), " ", type_of(c), " ", type_of(b), " ", type_of(n));
print("hex: {}, binary: {}, exponent: {}", 0xFF, 0b1010, 2.5e3);
i + f;
output
int float string char bool null
hex: 255, binary: 10, exponent: 2500.000000
== result: 45.140000

Integers are 64-bit (int64), floats are doubles. Hex (0xFF) and binary (0b1010) integer literals work, as do exponent floats (2.5e3). Strings support the usual escapes (\n, \", \\). (pinned: semantics/lexer_tests.cpp, semantics/type_info_tests.cpp)

Comments and the implicit result​

jaiscript
// single-line comment
/* multi-line
   comment */
auto x = 10; // trailing comment
x * 2;  // the last expression's value is what execute() returns
output
== result: 20

print and format​

print and format are registered by jai::stdlib::register_all as variadic host functions (they are the canonical example of variadics, which live on the host side — see the Functions chapter). (pinned: stdlib/io_tests.cpp)

jaiscript
print("plain string");
print("several", " ", "args", " ", "concatenate");
print("sequential: {} + {} = {}", 2, 3, 2 + 3);
print("positional: {1} before {0}", "cart", "horse");
print("literal {{braces}} in a formatted call: {}", true);
auto msg = format("format() returns: {}", 99);
print(msg);
print("no newline ", skip_newline);
print("continues the line");
output
plain string
several args concatenate
sequential: 2 + 3 = 5
positional: horse before cart
literal {braces} in a formatted call: true
format() returns: 99
no newline continues the line
== result: null

Rules:

  • print(value) — one argument: printed as-is (no {} processing).
  • print(fmt, args...) — if the first argument contains {} or {n} placeholders, it is treated as a format string: {} consumes the next argument, {0}/{1} are positional (0-based over the args after the format string), {{/}} escape braces.
  • print(a, b, c) — if the first argument has no placeholders, all arguments are concatenated.
  • Trailing skip_newline suppresses the newline; skip_flush suppresses newline and flush.
  • format(...) follows the same rules but returns the string instead of printing.

Note: brace escaping ({{) only applies on the format path (multiple arguments with placeholders). A single-argument print("{{x}}") prints the braces literally.

Stringifying values​

to_string(x) converts any value to a string; floats print with six decimals (3.14 → "3.140000"). For containers, to_string prints only a tag ([array], [map]) — use to_json(x) when you want the contents:

jaiscript
auto nums = [1,2,3];
print(nums);
print(to_json(nums));
print(to_json({"a": 1}));
output
[array]
[1,2,3]
{"a":1}

type_of(x) returns one of: null bool int float char string array map function object reference weak_ptr.
