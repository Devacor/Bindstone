The Kitchen Sink​

The smaller conveniences: enums, namespaces, destructuring, the ternary operator, and null-safe access.

Enums​

enum Name { a, b, c } declares sequential integer constants (0-based), accessed with dot syntax. They compare naturally and work as switch cases:

jaiscript
enum Direction { north, south, east, west }
print("east = {}", Direction.east);
auto d = Direction.south;
print("d == south: {}", d == Direction.south);
switch (d) {
    case Direction.north: print("going up");
    case Direction.south: print("going down");
    default: print("sideways");
}
Direction.west;
output
east = 2
d == south: true
going down
== result: 3

Enum members are plain ints at runtime (Direction.east prints 2). *(pinned: language/function_tests.cpp — enum_basic, enum_comparison, enum_in_switch)*

Namespaces​

Namespaces group functions, variables, and classes behind ::. They are flat — namespace my::nested::deep { } is a single namespace whose name contains ::, and "nesting" blocks composes the same way. Functions overload by arity; redefining an existing name+arity requires the override keyword (mirrors hot-reload discipline):

jaiscript
namespace utils {
    auto add(a, b) { return a + b; }
    auto add(a, b, c) { return a + b + c; }    // overload by arity
    auto VERSION = 3;
    class Vec2 {
        int x = 0; int y = 0;
        Vec2(int px, int py) { x = px; y = py; }
        auto len2() { return x * x + y * y; }
    }
}
namespace my::nested::deep {                    // flat name with :: in it
    auto answer() { return 42; }
}
print("utils::add(1, 2) = {}", utils::add(1, 2));
print("utils::add(1, 2, 3) = {}", utils::add(1, 2, 3));
print("version {}", utils::VERSION);
auto v = utils::Vec2(3, 4);
print("len2 = {}", v.len2());
my::nested::deep::answer();
output
utils::add(1, 2) = 3
utils::add(1, 2, 3) = 6
version 3
len2 = 25
== result: 42

Extra wrinkles, all pinned in foundry/suite_namespaces.cpp:

  • Duplicate name+arity without override → error (namespace_override_required); auto func(x) override { ... } replaces (namespace_override_allowed).
  • A namespace can share a name with a class and its functions then override the class's static methods of matching arity — lookup prefers namespace overrides, falls back to class statics (namespace_overrides_class_static, namespace_override_before_class — order doesn't matter).
  • Keywords like string are usable as namespace names (namespace_string_keyword_as_name).
  • Wrong arity / missing member through :: are runtime errors (namespace_function_arity_mismatch, namespace_member_not_found).

Destructuring​

auto [a, b, c] = array; unpacks positionally. Extra elements are ignored; missing ones bind null:

jaiscript
auto [x, y, z] = [1, 2, 3];
print("{} {} {}", x, y, z);
auto [a, b] = [10, 20, 30];       // extras ignored
print("{} {}", a, b);
auto [p, q, r] = [10, 20];        // missing become null
print("{} {} {}", p, q, r == null ? "null" : to_string(r));
auto pos = [4, 7];
auto [px, py] = pos;
px + py;
output
1 2 3
10 20
10 20 null
== result: 11

Ternary​

Right-associative, so the classic cascade reads top-down without parentheses:

jaiscript
auto health = 40;
auto status = health > 0 ? "alive" : "dead";
auto level = health > 75 ? "healthy" :
             health > 25 ? "wounded" : "critical";
print("{} and {}", status, level);
health > 50 ? 1 : 0;
output
alive and wounded
== result: 0

Null-safe access: ?.​

x?.member(...) evaluates to null when x is null instead of erroring — chains short-circuit:

jaiscript
auto obj = null;
auto a = obj?.length();          // null-safe: short-circuits to null
print("obj?.length() = {}", a == null ? "null" : to_string(a));
auto s = "hello";
print("s?.length() = {}", s?.length());
output
obj?.length() = null
s?.length() = 5
