Sandbox​

Write JaiScript and run it in this page. The engine is the one the games run on: the strict checker reads the whole program first, then the VM runs it. The standard library is here, with a file system that lasts until the page closes and the runner's console builtins (key_down, read_key, term_cols, term_rows). A program gets 20 seconds of script time, and Stop ends it at once.

Ctrl+Enter runs

The guide has a runnable sample in every chapter; paste one in.
