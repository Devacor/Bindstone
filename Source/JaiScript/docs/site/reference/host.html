    Engine API quick reference​

    One call per row; the linked embedding chapter explains it.

    Engine lifecycle & execution: Quickstart​

    APIWhat it does
    jai::engine::make()An engine, always a shared_ptr<engine>. No global state.
    jai::stdlib::register_all(eng)Opt-in stdlib: formatted print, format, to_string, to_json, time::, reflection, other optional helpers.
    A bare engineEngine core (math, array transforms, text and binary primitives), basic print, format_value.
    eng->execute(src)Runs a script; returns the last expression's value, a jai::script_value. A script the checker rejects throws jai::static_check_error before anything runs.
    r.as<T>() / as_int() / as_float() / as_string() / as_bool()Convert a result.
    eng->execute_file(path)Runs a file under its canonical path (listings, traces, breakpoints). A .jaibite in the .cache folder beside it caches the parse.
    eng->start(src) / start_file(path) / start(callable, args)Suspendable run: each sleep hands back a jai::script_run; resume() continues it once wake_at() has passed.
    eng->get_variable(name) / has_variable(name) / has_function(name)Read a global; a function is a value too.
    fn.as_function()(args)Calls a script function; returns checked_result<script_value> (text: eng->format_error(r)). An uncaught script throw arrives as jai::script_exception.
    engine::external_call_guardWraps that call only while a script is running.
    jai::convert_script_function<Sig>(fn)Typed std::function over a script function. A script error or uncaught throw throws jai::runtime_error to the C++ caller; a host function called from script returns it as that call's error.
    v.as<std::vector<T>>() / as<std::map<K, V>>()Typed arrays and maps copy out.
    as_array()Views an array<var> only.
    unchecked_array_node()->for_each(eng, f)for_each walks any array kind.
    eng->set_backend(jai::backend_type::interpreter)The tree-walking interpreter; the bytecode VM is the default. Before the first execute only, in a program that links jaiscript_interpreter.
    eng->set_output_stream(s)Redirects print(); nullptr restores std::cout.
    eng->set_script_error_handler(fn)Sink for script errors nothing can catch (a destructor failing at engine teardown).
    eng->format_stack_trace() / last_stack_trace()Script stack of the most recent failure.

    Registering the host surface: Quickstart, dynamic_binder​

    APIWhat it does
    eng->add_function(name, lambda)Typed host function. Repeated names form an overload set resolved by argument types.
    Non-const T& parameterThe callee's final value is written back into the script lvalue argument (variable, field, element, map value, static, C++ property, vector component v.x) by that slot's store rule. A literal or temporary is a copy.
    std::shared_ptr<T> or std::weak_ptr<T> parameterTakes null as an empty handle.
    std::weak_ptr<T> parameterTakes a live shared_ptr or weak_ptr handle as one to the same object.
    eng->add_variadic_function(name, fn)Receives the raw std::vector<script_value>: print-shaped functions, optionals.
    add_function(name, fn, jai::nodiscard | jai::serial | jai::filesystem)The trailing option, also on add_variadic_function, .method and .static_method: a privilege the call requires, jai::nodiscard (a statement that drops the result fails the load: host [[nodiscard]]) and jai::serial (a parallel body may not call it: parallel calls), combined with |. eng->is_nodiscard_function(callable) asks.
    eng->add_host_direct(name, arity, invoke, target)Direct entry for the function name holds: a VM call site with arity non-reference arguments calls invoke(target, args, arity) over the arguments in place. The function takes every other call.
    eng->add_global(name, value)Copies a value in.
    eng->add_global_ref(name, var)Live binding (cpp_bound) to a C++ primitive or string: script reads and writes the real variable.
    eng->make_value(v) / make_null() / make_array() / make_map()Value factories; every script_value carries its engine. make_value of a script_value hands it back; as<script_value>() is the value itself.
    jai::dynamic_binder<T>(*eng, "Name")Class binding: .constructor<Args...>() .method(...) .property(...) .static_method(...) .static_property(...) .base_class<B>(). See binder verbs.
    .method("+", &T::operator+)Operator by token name: bound operators.
    extend(object, Class) (script)Gives a host-owned object a script class over its C++ class or a base, in place. Idempotent; re-derives for another class (Script-Extensible Objects).
    eng->extend(obj, "Class")The same from C++. add_global, make_object and every other entry hand script the object's layer, extended before or after.
    eng->script_layer(*obj) / script_layer_detach(obj)The object's live layer / drop it (fields returned as JSON).
    obj->script_layer_to_json() / script_layer_from_json(s)script_extensible (every property_owner): the layer's {"$type", "$script"} state, out and back.

    eng->hot_reload_reporting(true) / hot_reload_reports() / clear_hot_reload_reports()Off by default. On: each field operation of a class reload on live instances, and each saved value a load converts or cannot fit, aggregates into std::vector<jai::field_migration_report> until cleared.
    Report rowclass_name, field_name, old_type, new_type, outcome (preserved / converted / reset / added / removed), count across instances.
    eng->disable(jai::filesystem) / enable(...) / is_enabled(...) / register_privilege("name")The filesystem privilege (on by default) and custom named permissions.

    APIWhat it does

    eng->last_check_diagnostics()Report of the last checked execute/bite, warnings included.

    eng->jaibite_cache_directory(dir, root) / jaibite_cache_directory()Caches go below dir at the source's path relative to root (outside it, or with no root, its own path). A valid .cache beside the source still loads, never rewritten. For read-only bundles; empty restores the default.
    eng->jaibite_cache_path(source)The cache file written for source; empty for a .jaibite source.

    Thread pool: Thread Pool for Host Work, Parallel worker count​

    Each call with a compiled example: Thread Pool for Host Work. A task is a thread_pool::task_type, a std::function<void()>.

    Call (<jaiscript/thread_pool.hpp>)Does
    thread_pool(n = 0)Starts n workers and keeps them for the pool's lifetime. Neither copyable nor movable.
    thread_pool(0)0 means thread_pool::default_worker_count(): one less than the hardware threads, never less than one.
    worker_count()The number of workers.
    submit(task)Shared queue: the first free worker runs it.
    submit_to(worker, task)That worker's own queue: only its thread runs the task, in submission order, between the shared tasks it also takes. For thread-affine state.
    submit_to, bad indexAn index outside 0 to worker_count() - 1 throws std::out_of_range.
    submit(task, then, where)Runs then once after task returns or throws.
    submit_batch(tasks, then, where)Queues a std::vector of tasks under one lock and runs then once after the last finishes. An empty batch continues at once.
    submit_batch, queueing throwsThe tasks already queued run, then is dropped and the caller gets the exception.
    wherethen_on::pool (default): on the worker that finished the work. then_on::posted: on the thread that calls run_posted().
    wait_idle()Blocks until every task submitted so far has finished, pool continuations included, and their captures are destroyed. Does not wait for posted work.
    post(task)Queues a task for the draining thread, from any thread.
    run_posted()Runs the posted queue on the calling thread, in posting order, and returns how many tasks ran.
    on_exception(handler)Installs a std::function<void(std::exception_ptr)>; replaceable at any time from any thread.
    spin_budget_ns(ns), spin_budget_ns()Sets and reads how long an idle worker spins before it parks (default 1,000,000: 1 ms).
    thread_pool::performance_core_count()A hybrid CPU's performance cores, between 1 and the hardware threads; detected once.
    jai::thread_pool pool{n, jai::thread_pool::fast_threads}Workers that ask the system not to throttle them to save power (off by default).
    spin_budget_ns(0)Parks at once.
    eng->parallel_thread_count(n) / parallel_thread_count()Threads of a parallel region, the caller included. Default: the performance cores, at most the hardware threads minus one; 0 restores it.

    dynamic_binder: Binding C++ Classes​

    When a bound object is copied or shared​

    The boundary never copies; from there a bound object behaves as a script class instance does (chapter).

    ScriptResult
    A value into a variable, field or element (Turret b = a;, var c = b;), a by-value parameter or return, a container literal element ([a]), a by-value capture ([a], [=])A separate C++ object made by the copy constructor.
    A call's T& result into var c, auto c or Turret cA copy, as C++ auto drops the reference.
    A T& argument the host passes into a var p or Turret p parameterA copy.
    A reference: var& g = gate;, auto& c = owner.child();, C& c, a & parameterThe same object. c = other; runs the class's bound =.
    A handle: new Turret(...), a shared_ptr<Turret> variable, a std::shared_ptr<Turret> the host returns, passes to a callback, or gives add_global or make_objectEvery copy of the handle shares the one object: var g = gate; names the host's gate.
    A class with a deleted copy constructor (std::atomic, std::mutex)Each copy above raises Cannot copy C++ object of type 'T': the type is not copy-constructible. Hold it by reference (auto&/var&) or share it (shared_ptr<T>).
    A typed slot the object converts into: int n = obj; as a declaration, assignment, parameter, return or fieldCalls the bound to_int on the object itself, with no copy.
    A float, bool, char or string slotCalls to_float, to_bool, to_char or to_string.
    Assigning into a variable, field or element declared C (a = other;)Runs the bound = on the held object. With none bound, a copy-constructed object replaces the held one.
    Assigning into a var variableTakes a copy of other in place of what it held.
    A bound property passed to a & parameter: gate.level, or this.level or a bare level inside a method of a script class deriving SpawnerBinds the property itself; the callee's writes land in the C++ member.
    A bound property in a lambdaA [=] lambda copies its value at creation; a [&] lambda reads the live property.

    Binder verbs​

    Explained in The binder chain, verb by verb.

    VerbWhat it binds
    .constructor<Args...>()A constructor overload, resolved by arity and C++ parameter types.
    .constructor<>()Prefers a T(engine*) constructor when the type has one.
    .method(name, &T::fn)A member function, const or not. A member data pointer here is a compile error that points to .property().
    .method(name, lambda)A lambda whose first parameter is T& or const T& is a method on that object.
    Any other lambdaA method that ignores its receiver (.method("twice", [](int64_t k) { return k * 2; })).
    A stateful functorKeeps one state on every call path.
    OverloadsRegistering a name again with another C++ signature, same arity included, adds an overload.
    .static_method(name, fn)A free function or lambda, called as Vec2::axes(). Bound-class arguments work.
    A static method returning a bound classDoes not compile: return primitives or strings, and bind a constructor overload or an engine-level function as a factory.
    .property(name, &T::member)Field access. A setter is generated only for a copy-assignable member type. For a class with no serialization route of its own the member is a key of its archive record, written and read in place; a const member stays out (binding records).
    A std::vector<E> memberBinds as a live view without a copy (size, push, pop, at, []).
    A member of a registered class typeBinds by reference.
    A jai::signal<Sig> or signal_emitter<Sig> memberBinds as a connect surface.
    .property(name, getter, setter)A computed property from lambdas or a member function pair. A nullptr setter makes it read-only: a store raises Cannot assign to 'x': it is read-only. In a binding record the getter's value is written, and a load reads over it and hands it to the setter; a read-only one stays out.
    .transient_property(name, &T::member), .transient_property(name, getter, setter)The same property, kept out of the class's binding record, as JAI_TRANSIENT_PROPERTY is out of a property_owner's.
    A member of a class type not registered yetBinds; the type may register later, in any order (std::shared_ptr<Node> next inside Node's own chain). The first load, check or host call into script raises Bindings are incomplete: with one line per type still missing: the class and member, the C++ type and the registration to write.
    .static_property(name, &var), .static_property(name, getter, setter)A class-level value, read and written as Class::name. The pointer form binds the live variable.
    .base_class<Base>()An inheritance edge: base methods and properties are callable on the derived with virtual dispatch, and a Base slot may hold this type on a polymorphic load. Diamond inheritance throws. A binding record writes the base's binding first, and a polymorphic one takes its $type from the binding's name.
    .auto_bind(mode)Everything the declarations know: property_owner schema properties, observables and signals; base classes; and to_string(), size(), empty() and ==/!= where the class has them. Modes: all, properties, hierarchy.
    static T::jai_auto_bind(dynamic_binder<T>&)A hook through which a class binds its own private members.
    .transparent_wrapper(unwrap)An operation not found on the wrapper retries on the unwrapped value: gate.threat + 2 reads the observable's int while .on_change stays on the wrapper.
    .post_load_hook(fn)The class's post_load, [](T& self) or [](T& self, int version), run by a script-side load (from_json, from_binary, from_base64) after it writes the fields, and by a C++ archive after it loads a binding record.
    .version(n)A number (default 1) for the script archives only; the C++ archives never read it (versions).
    .deserialization_factory(fn)Constructs a non-default-constructible type on load. The archive-only, context-only and context-plus-archive signatures are detected.
    .serial_only_constructor(), .method(name, fn, jai::serial), .static_method(name, fn, jai::serial)Keep the constructor or the call out of parallel bodies.
    .bound_engine()The engine this binder targets, for a configure function that calls bind_signal_type or adds globals.
    .build()Optional: commits the registration there and throws what fails. Without it the binding commits when the binder's lifetime ends, or at the engine's first load while the binder is still alive; a failure then joins the Bindings are incomplete: error of the next load. Chain calls after the commit apply to the registered class. A binder moves but does not copy.

    Bound operators​

    Operators are methods named by token and follow the script rules of the operators chapter.

    BindingRule
    Tokens+ - * / % & | ^ << >> == != < <= > >= <=>, unary - + ~ (a lambda taking only the object), [], (), =, and to_bool for !v and if (v).
    Supplied<=> supplies < <= > >= and ==; == supplies !=; 5 == m asks m's == taking an int.
    ++, --C++'s two forms, which a script class cannot declare: a lambda taking only the object answers ++v; one taking the object and an ignored int64_t answers v++.
    A missing ++ or -- formCannot apply '++' to T
    Compound ("+=" ...)Runs once on the object in place, for a variable, field, element, map value or reference. Nothing is stored back; the expression is what the operator returns.
    Compound, none boundm += o is m = m + o.
    ReflectedA lambda whose first parameter is another type and whose second is the class, C++'s free operator-(int64_t, const Money&), answers 5 - m.
    No reflected formArithmetic never reverses on its own; the checker warns at a number left of a bound class's operator that has none.
    Overload choiceAn operator counts for an operand only when one of its overloads takes it.
    operator<(const Money&) and operator<=>(int64_t) boundm < 5 runs the <=>.
    Only operator+(const Money&) boundm + "!" is the builtin concatenation of m's text.
    No matchNo bound 'Money * int': bind operator "*" taking int on Money, or convert the operand

    Safety rails: Safety Rails​

    Named permissions​

    Explained in Named permissions for your APIs.

    CaseRule
    register_privilege(name)Returns nothing. A new name starts disabled.
    Registering a name again, or registering "filesystem" (the built-in flag)Leaves the grant as it is.
    An unknown nameA query is false. Enabling, disabling, requiring or attaching it to a callable is rejected, never auto-registered: register names before binding functions that require them.
    A missing permissionInsufficient privilege: savegame.write.
    Several missingThe text names a built-in first, then the first custom one in registration order, whatever the list order.
    Several enginesNames are reusable across engines; registration and grants are per engine. There is no global registry.
    CostA binding resolves its requirements once to engine-local slots: a call's check looks up no name, allocates nothing and takes no lock or atomic. Registration and binding may allocate.

    Depth limits​

    Only script calls have a counted cap; the errors are catchable, the static listing's aside (chapter).

    DepthBoundError
    Script callsA per-engine cap for each backend: 256 active calls on the interpreter, 250,000 on the VM.Maximum recursion depth exceeded - possible infinite recursion (uncaught, the error reads as this text alone)
    Native stack at a callLess than 256 KB of stack left, whatever the cap.Native stack exhausted before the call-depth cap: the host thread's stack bounds this recursion
    Which stackThe host thread's, or an engine::start run's own fiber stack. Windows, Linux, Android and macOS report its bounds; a stack the OS calls unlimited counts as 1 GB.
    Source nesting: parser, checkerEach stops with 192 KB of stack left.nesting too deep for the host thread's stack in the static listing, one error at the deepest point reached
    Source nesting: VM compiler, interpreter's evaluationThe same margin.Nesting too deep for the host thread's stack when the code runs
    A platform that cannot report its stack's boundsThe source walks stop 1 MB below where the walk started: give a script-loading thread there more stack.

    Static checking: Static Checking​

    Member checks​

    A member missing from a fully known class is a load error (Members).

    MemberRule
    AccessorsA member a user _get_x/_set_x declares anywhere in the chain is known, and typed when the declaration is unambiguous (the map lists the ambiguous shapes).
    One parameterless, non-coroutine int _get_hp()Makes char c = obj.hp an error.
    One by-value void _set_hp(int)Makes obj.hp = "s" the error cannot assign 'string' to property 'hp' declared 'int'.
    Bare names in a classA bare name in a method resolves locals, then members, then globals, the run-time order: a bare x is checked as the field and ::x names the global.
    Enum valuesChecked for existence: no value 'zzz' in enum 'Direction'.
    Builtin methodsA method of a known string, array or map: its name, its argument count and each argument's shape (a number, text, an array, a map, a function) as the API reference states it.
    Bound methodsA method the binder bound on a known receiver: its argument count and each argument against the C++ signature, unless a script class below the bound class declares the method or the object was extended.
    UncheckedSubscripts, and the handle builtins of a shared_ptr (use_count, cpp_ref_count, unique, same_as, reset).
    A class method named as a builtinWins. Where the program holds that class or a subclass by shared_ptr, the method warns that the builtin is unreachable on its handles; a class held only by value keeps its reset() unwarned.
    Open classesAn ancestor the checker cannot resolve opens the whole class: no member diagnostics.

    What still fails at run time (the precision map)​

    The whole list of spots where the checker is silent: a mistake there is a run-time error, never a load error (chapter).

    Lenient by designWhy
    var anywhere, and everything computed from it; a null initializerNo declared type to check against.
    auto without an initializerauto locks at a store the checker cannot order.
    Stores through an auto&, a var& or a reference to a classThe referenced variable's table runs at run time. A store through a T& of a scalar, text, container or math type is checked as a T slot's; binding the reference and member lookup through it are checked too.
    Container elements the checker cannot type: map keys, elements of untyped containers and var receivers, subscripts, builtin container/string method resultsThe runtime element boundary is the check.
    Literal elements, pushes and element stores into a declared array<T> or map<K,V>Checked.
    Engine globals (typed off the value tag; a later retag is invisible), host-object conversions, callables held in variablesNo static signature in view.
    Host parameters that take any value or a bound object, a bound method a script subclass declares again, binder properties, a name declared extern function f;The C++ signature does not decide them. A host function's and a bound method's count and primitive, text and container arguments are checked.
    A function or global two units declare, a class-typed global of another unitMore than one declaration could answer, or the slot may hold a subclass. One unit's function signature and typed global are checked in every other unit of the program.

    ar.get_version()Answers the same number for the record opened last.

    Binary format​

    Both formats run the same calls. JSON writes a record as an object of its properties; a record opened with a type name leads with "$type", then "$version" when it is above 1. Binary is little-endian.

    property byte sizesA reader jumps to a property by name and skips unknown ones unparsed.
    array0x03, a count, the elements, 0x04
    map0x05 … 0x06
    null0x00

    NetworkingBehavior
    NetChannel()One framed TCP connection: listen(port) waits for one peer, connect(host, port) dials one, send(bytes) queues a packet, pump() moves the bytes and fires the signals, close() drops the connection.
    connected(), status()"idle", "listening", "connecting", "connected", "closed: <reason>", "error: <reason>"
    NetChannel signalson_connect(), on_packet(bytes) and on_disconnect(reason)
    NetChannel.connect is asynchronousfalse only when the attempt fails at once (the host name does not resolve, the socket cannot be made), reason in status(). Otherwise true while the connection is still being made.
    Connect outcomeArrives through pump(): on_connect() when the peer accepts, on_disconnect("connect refused") when not. Packets sent before then wait in the queue.
    NetServer()Many framed TCP clients on one port: listen(port), send(id, bytes), broadcast(bytes) (the count of clients it reached), pump(), kick(id), client_count(), listening(), close(). Client ids count up from 1, never reused by one server.
    NetServer signalson_client_connect(id), on_client_packet(id, bytes) and on_client_disconnect(id, reason)
    PacketOne send's bytes, delivered whole and in order. On the wire: a 4-byte big-endian length, then the bytes.
    ThreadsNone. The sockets do not block; signals fire only inside pump(), on the script's own call stack. A game calls pump() once a frame.
    Disconnect reason"closed by peer", "recv error", "send error", "oversized frame" (a length over 64 MiB) or, for a server's client, "kicked".
    Packets ahead of a closeDelivered before its disconnect.
    net_host_name() -> string, net_local_addresses() -> array<string>This machine's name and its IPv4 addresses, loopback left out.

    Performance rules of thumb: Backends, Performance​

    RuleWhy
    Reuse enginesEngine creation dwarfs a small script's execution.
    Prefer jaibite for anything run more than onceThe handle skips the parse; the VM also caches the compiled chunk.
    Repeated execute(string) is already cheapAn LRU source cache (64 entries): identical strings skip the parse.
    The VM backend is the fast one for hot loopsLoops fuse into superinstructions; the interpreter remains the reference for debugging.
    Pass heavy things by &A by-value copy of a big structure deep-copies it.
    Declare hot containers with an element typearray<int> / array<float> are raw buffers and skip the per-element boxing.
