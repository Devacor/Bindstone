Conventions​

  • A handle is a shared_ptr<T>; a reference is a T&.
  • The checker is the static checker that runs before any script executes. It is always strict; a [[warn_mode]] region is the opt-out (attributes).
  • A load error is one the checker or the parser reports before anything runs; a run-time error is one catch sees (which is which).
  • A rule that needs more than a row links to the guide section that shows it running.
