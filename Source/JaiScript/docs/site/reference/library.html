    JSON and key order​

    JSON encoding​

    to_json(x) writes compact JSON, to_json(x, n) indents n spaces per level, from_json(text) reads it back. to_binary and from_binary round-trip the same values. Loading rules: JSON.

    ValueJSON
    a map with string keys, an array, a string, bool, nullan object, an array, a string, true/false, null
    an int, a floatA number that reads back as the same kind. A float is written with every digit it needs to read back exactly.
    a map whose keys are not strings{"$map": [[key, value], ...]}
    a char{"$char": 65}
    a float JSON cannot spell{"$float": "inf"}, "-inf" or "nan"
    a class instance{"$type": "Hero", "$val": {fields}}
    a shared_ptr handle, the first to its objectThe object, once: {"$id": 1, "$type": "Hero", "$val": {...}}
    a shared_ptr handle, every later one{"$id": 1}
    a weak_ptr handleThe same with $ref in place of $id. An expired one is null.

    Map key order​

    Keys follow one total order, the order a map iterates and serializes in. Lookup is hashed. More: Key types.

    KeyIdentity and order
    numbersBy value. 0.0 and -0.0 are one key. Every NaN is one key, ordered after the numbers.
    different kindsNever one key: 1 and 1.0 are two, and a utf8_string is not the string of the same text.
    a char and its one-character stringOne key, ordered as the string. The entry keeps the spelling that made it.
    a char key in a map<string, V>Stored as its string.
    a one-character string key in a map<char, V>Stored as its char. A longer string raises the char conversion's error.
    an array, map or handleBy the identity of the object it holds, never its contents: two equal array literals are two keys.
    a class value with operator< or operator<=>Ordered by it. Two keys are one when neither is less.
    a class value with int hash() and neitherKeyed by hash() and operator== (identity without one), iterated by hash() value.
    a class value with none of theseBy identity, with the warning map keys of class 'C' compare by identity: declare operator<=> (or operator<) or hash() to key its values by value
    class keysIterate grouped by class name, ahead of handles.

    Binary data​

    A string holds any byte. s.to_bytes() and string::from_bytes(bytes) convert to and from an array<uint8>. Errors, limits and file reads: Binary data.

    binary::reader​

    s.reader() or binary::reader(s) reads the string from a cursor at 0, little-endian. Every read advances the cursor.

    Reader callReads
    int8() int16() int32() int64()A signed integer.
    uint8() uint16() uint32()An unsigned integer. There is no uint64(): int64() reads the same eight bytes as a signed value.
    float32(), float64()A float. float32 widens, float64 keeps every bit.
    text(n)An n-byte text field, C's char[n]: the cursor moves exactly n. The text is the bytes before the first NUL (all n when there is none).
    text()A C string: the bytes before the next NUL. The cursor moves past the NUL.
    bytes(n)Exactly n raw bytes as an array<uint8>.
    big_endian(), little_endian(), seek(pos), skip(n)Set the byte order or move the cursor. Each returns the reader, so calls chain.
    pos(), size(), remaining(), at_end()Ask: the cursor, the byte count, the bytes left, whether the cursor is at the end.
    unpack(layout), unpack(name, width, ...)A layout's fields in order, as a map<string, var>.
    read(Class, layout)A default-constructed instance, its fields filled in declaration order, base fields first.
    read: class against layoutThe field count and each field's kind (int, float, string for text, array for bytes) must match the widths.

    binary::writer​

    binary::writer w; mirrors the reader. Each call returns the writer.

    Writer callWrites
    int8(v) to int64(v), uint8(v) to uint32(v), float32(v), float64(v)The number. One that does not fit raises and writes nothing: Cannot write 256 as uint8 (0 to 255).
    text(s)The text, then a NUL. A text that holds a NUL raises Cannot write text: the text holds a NUL at byte 3; raw data goes through bytes.
    text(s, n)An n-byte field: the text, then NULs to n. A text of exactly n bytes fills the field with no terminator.
    text(s, n), text longer than nRaises Cannot write text: the text is 9 bytes, longer than text(8).
    bytes(b)Raw bytes: a string's, or an array of 0–255.
    pack(layout, map)The map's values in the layout's order. A missing name or a value that does not fit raises before anything is written.
    big_endian(), little_endian(), seek(pos)Set the byte order; go back to patch an earlier field.
    pos(), size(), to_string()The cursor, the byte count, the bytes.

    Regular expressions​

    regex(pattern) and regex(pattern, flags) make a regex value. Matching is linear in the text: no pattern backtracks. Taught in Regular expressions; the constructs that are errors: no backtracking; bytes against characters: text kinds; load-time compilation: constant patterns.

    Calls​

    CallAnswers
    r.search(text), r.search(text, start)The leftmost match at or after start, a regex::match, or null. The text before start still counts for ^ and \b.
    r.matches(text)Whether the whole text matches, any way through the pattern: regex("a|ab").matches("ab") is true.
    r.find_all(text)Every match, left to right, as an array of regex::match.
    r.replace(text, with), r.replace_first(text, with)The text with every match (or the first) replaced by a replacement text, or by what a function returns for the regex::match.
    r.split(text), r.split(text, max_splits)The pieces between matches. Each split's capture groups follow its piece. A count keeps the rest in the last piece.
    r.pattern, r.flagsThe pattern and flags it was made with (read-only).
    regex::escape(text)A pattern that matches the text literally.
    m.text(), m[0]The whole match.
    m[i], m["name"]A group by number or name; null for a group that took no part. A group in a loop keeps the text of the loop's last pass.
    m.start(g), m.end(g)Its positions (group 0 when g is left out); -1 for a group that took no part.
    m.size()The whole match plus every group.

    Syntax​

    ConstructMatches
    a, \., \t \n \r \f \v \0The character. A backslash before punctuation or a space takes it literally; before a letter that names nothing it is an error.
    \xNNA byte on a string; U+00NN on a utf8_string.
    \uXXXX, \u{X}A code point (its UTF-8 bytes on a string).
    .Any character but a newline (with flag s, any).
    [abc], [a-z], [^...], [], [^]One character of the set, or not of it. - first or last is literal, [] matches nothing and [^] anything.
    \d \w \s, \D \W \SAn ASCII digit, word character (letters, digits, _) or whitespace (space, tab, newline, carriage return, vertical tab, form feed), or anything else. Inside a class too.
    ^, $The start or end of the text (with flag m, of a line: \n ends one). $ does not match before a final newline.
    \A, \zThe start or end of the text, whatever the flags.
    \b, \BA word boundary, or a position that is not one.
    (...), (?<name>...), (?:...)A capture group (numbered from 1 by its opening parenthesis), a named one (also numbered), a group that captures nothing.
    x|yThe first alternative that leads to a match. An empty alternative matches empty.
    * + ?, {n} {n,} {n,m}Repetition, as many as possible. A count runs to 1000. A brace that starts no count is a literal brace.
    *? +? ??, {n,m}?Repetition, as few as possible.
    (?i), (?-i), (?i:...)Turns flags on or off to the end of the enclosing group, or inside the group alone (any of i m s x).

    Flags​

    FlagEffect
    iLetters match either case (ASCII letters).
    m^ and $ match at line breaks.
    s. takes a newline.
    xSpaces and # comments outside a class are ignored.
    another letter, or one twiceRaises.

    Replacement text​

    In a replacement textInserts
    $1 to $99A group, taking the longest number the pattern has: $10 with one group is $1 then 0.
    $0The whole match.
    ${n}, ${name}A group by number or name.
    $$A dollar sign.
    a group that took no partInserts nothing.
    a group the pattern lacks, or a $ before anything elseRaises: regex: the replacement names group 2 at position 0, but the pattern has 1 group

    executable_dir() (alias bin_dir()), executable_path()The running executable's folder and file, fixed for the process.

    Encoding and query strings​

    Taught in Percent-encoding and Query strings.

    FunctionRules
    web::url_encode(s)RFC 3986, for a path segment or any other URL part: A-Z a-z 0-9 - . _ ~ stay, every other byte is %XX in upper-case hex (PHP's rawurlencode).
    web::form_encode(s)application/x-www-form-urlencoded, for a form body or query string: A-Z a-z 0-9 * - . _ stay, a space is +, every other byte is %XX (PHP's urlencode).

    web::parse_query(s)A map<string, string>; keys and values are form-decoded.

    web::build_query(m)Form-encodes a map, joined with & in the map's key order.
    web::build_query valuesA string, number or bool is written as to_string writes it. An array repeats its key per element. A null value drops its key.
    web::build_query errorsAny other value raises web::build_query: the value of 'm' is a map (or ... is not text, a number, a bool or an array of them).

    Random generator algorithm​

    The formulas behind random, from Randomness: the algorithm, exactly. Every formula is part of the language, so a seed draws the same bits everywhere.

    StepDefinition
    generatorxoshiro256** 1.0 (Blackman and Vigna): four 64-bit words; a draw is rotl(s1 * 5, 7) * 9.
    seedingThe words are four successive splitmix64 outputs from the seed: x += 0x9E3779B97F4A7C15, then z = (x ^ (x >> 30)) * 0xBF58476D1CE4E5B9, z = (z ^ (z >> 27)) * 0x94D049BB133111EB, z ^ (z >> 31).
    next_int(lo, hi)Lemire's method over span = hi − lo + 1: the high word of draw × span, redrawn while the low word falls under (264 − span) mod span.
    next_int over the whole int rangeOne raw draw.
    next_float(lo, hi)fma(u, hi − lo, lo) with u = next_float(), one rounding; a result that rounds up to hi is the float just below it.
    shuffleFisher–Yates from the last index down, element i swapped with the one at next_int(0, i).
    pickThe element at next_int(0, size − 1).
    parallel streamsElement i (the chunk, for parallel_reduce) of a loop that captures a generator draws from the stream splitmix64 seeds from mix(draw ^ mix(i + 0x9E3779B97F4A7C15)).
    draw, mixdraw is the statement's one draw from the captured generator; mix is the seeding's output step.

    What a bare engine has. jai::engine::make() alone runs the whole language with these builtins:

    • a print that concatenates its arguments, and template strings with format specs (format_value)
    • the builtin container and string methods and their array:: forms
    • math:: (functions, vectors, colors, wrap_*), regex, and binary:: readers and writers with string::from_bytes
    • same_object, extend, thread_count, parallel_transform and parallel_reduce, sleep
    • the location builtins (executable_dir, file_data, resolve_path and the rest)

    jai::stdlib::register_all adds the formatted print, format, to_string, type_of, JSON and binary serialization, the string:: functions, to_char, random, time::, crypto:: and reflect::. web:: and spider:: are separate opt-ins.
