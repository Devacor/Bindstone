    Language Rules​

    One rule per row. The guide section linked from a row shows the rule running; an error text quoted here has its row in Errors and Diagnostics.

    Two spellings, one meaning​

    JaiScript reads as C++ or as JavaScript. Each row's two columns are the same construct. One pair differs in behaviour: a [] lambda captures only what its list names, while an arrow or a function(...) expression captures its whole scope by reference (as [&]).

    ConstructC++ spellingJavaScript spelling
    Named functionint f(int a) { ... }function f(a) { ... }, function f(int a) -> int { ... }
    Anonymous function[x, &y](int a) { ... }: captures what it lists(a) => expr, (a) => { ... }, a => expr, function(a) { ... }: capture by reference
    Dynamic variablenone (auto takes its initializer's static type)var x, let x
    Null literalnullptrnull
    One shared objectmake_shared<T>(args)new T(args)
    Floating-point typedouble, float (one type)none (a literal with a . is a float)
    Non-public membersprivate:, protected: (one level: the class and its subclasses)none
    Textual inclusion#include "x.jai"include "x.jai"

    Words from other languages (virtual, delete, goto, extends, constexpr, const_cast, ===, function*, &x) are not reserved; where one fails to parse, the error names the JaiScript spelling (catalogue, Language Bridges). const is a keyword; C++'s other places for it (a const method, a const return type, array<const int>, shared_ptr<const T>) each raise their own text.

    Operators​

    Chapter: Operators & Arithmetic.

    CategoryOperatorsRule
    Arithmetic+ - * / %int op int stays int (7 / 2 → 3); any float operand promotes.
    String ++Joins text; a char beside a string joins as its character. A number, bool or null beside a string is an error: write to_string(x) or `${x}`.
    Unary+ - ! ~+: identity on a number, a char (promoted to its int) and a math value (a copy). - also negates a math value. ~: an int only.
    Step++ --Prefix and postfix, on every lvalue (elements, map entries, members).
    Assignment= += -= *= /= %= &= |= ^= <<= >>=Typed targets convert C++-style. x op= y is x = x op y with x evaluated once; the right side runs before any part of the target.
    Assignment targetsEvery C++ lvalue: a call returning T&, a conditional of lvalues, (a = b) = c, ++x = v, cast<T&>(e).
    Comparison== != < > <= >=1 == 1.0 is true. A char beside a string compares as its one-character string (s[i] == "x"). NaN follows IEEE (false and unequal).

    Ternary?:Right-associative. An int arm and a float arm make a float.
    Arrow function(params) => expr (params) => { ... } x => exprA function expression that closes over its scope by reference, like function(...).

    Integer and char arithmetic​

    CaseRule
    Integer overflow+ - *, unary - and INT64_MIN / -1 raise a catchable error in the default build (JAISCRIPT_CHECKED_OVERFLOW). Integer arithmetic is never undefined behavior.
    Division by zeroInteger / and % by zero raise a catchable error. With a float operand they are IEEE: an infinity or NaN.
    Deliberate wraparoundmath::wrap_add / wrap_sub / wrap_mul.
    char operandsPromote to int (unsigned, 0..255) under arithmetic, bitwise and comparison operators: 'a' == 97 is true, 'z' - 'a' is 25, s[i] > 127 is an unsigned high-bit test (byte 0xC3 is 195, never -61).
    int → charNever implicit: type_of('a' + 1) is "int".
    Making a charcast<char>(n) (range-checked 0..255), cast<char>("a"), to_char(n), a \xNN literal. Out of one: cast<int>(c), cast<string>(c).

    Operators on script classes​

    A class declares an operator as a method (Vec operator+(Vec o)). It runs only when the (left) operand is an instance whose class chain declares it; every other operand keeps the builtin meaning.

    OperatorRule
    Declarable setC++'s overloadable set less && || , -> new delete and !: binary + - * / % & | ^ << >> < > <= >= == != <=>, unary - + ~ (told apart by the parameter count), =, [] and ().
    a op= ba = a op b through operator op; there is no operator op=.
    =Into an existing object (a slot declared the class, a var): operator= when an overload takes the value, else the implicit memberwise copy. Initialization copy-constructs.
    !=, relational!= without an operator!= negates operator==. A relational operator the class does not declare uses <=>.
    Truthinessbool to_bool(): if (v) calls it and !v negates it. Declaring operator! is the parse error operator! cannot be declared: !v is !to_bool(v); declare bool to_bool().
    operator()Makes an instance callable (v(1, 2)). A function slot still takes only functions and null: wrap the instance in a lambda.

    Type conversions​

    jaiscript
    class Meters { float v = 0; Meters(float x) { v = x; } }
class Reading { int raw = 0; Reading(int r) { raw = r; } int to_int() { return raw * 10; } }
Meters m = 3;              // one-step converting constructor
int n = Reading(4);        // to_int() on the way into an int slot
float f = 7;               // widens
int t = cast<int>(3.99);   // a float enters an int only through cast
bool b = 5;                // truthiness
string s = to_string(42);  // text only: stringify explicitly
print("{} {} {} {} {} {}", m.v, n, f, t, b, s);
    output
    3.0 40 7.0 3 true 42

    One table governs declarations (int x = e), assignment (x = e), by-value parameters, return values, instance and static field stores, and the elements of typed arrays and maps. A conversion is one step: a converting constructor or a to_X() method runs, never a chain (X.to_int() then C(int) is not implicit); one that throws shows its own error. Between typed sides a mismatch fails the load; out of a var the same rule raises at run time (Diagnostics).

    TargetAcceptsRefuses
    intint; bool (true → 1); an enum value; an object with to_int()A float (rule). string, char, null, containers: no implicit parse ("42".to_int()).
    floatfloat; int (widens); bool; an object with to_float()A string: s.to_float().
    boolbool, int, float, null, an object: truthiness (5 → true, 0 → false)A string, an array or a map into a declared bool: a load error (!s.empty()). Conditions keep truthiness for all of them.
    enum Ea value of E; an int out of a var that is one of its valuesAn int or another enum's value: cast<E>(n) converts an int that is one of its values.
    string / utf8_stringeither text kind (a utf8_string's bytes, a string's characters); a char (its one-character text); an object with to_string()int, float, bool, null, containers: no implicit stringify. Write to_string(x) or `${x}` (Printing values).
    charchar; a string of exactly one character; an object with to_char()A string of another length: Cannot convert 'string' to 'char': a char takes a string of exactly one character (a literal fails the load). char c = 65: write cast<char>(65).
    array<T> / map<K,V>an array / a mapAn element or key of the wrong type, on every store: at load where the checker sees both types (cannot push into 'array<int>': expected 'int', got 'string'), else at run time (Cannot store string in array<int>, Cannot push 'string' to array<int>).
    an elementits exact type; an int into a float element; bool and int both ways; char and string both waysAnything else: no truthiness and no to_X() at the element boundary.
    a map keythe declared key type; a char key and its one-character string are one key (stored as the declared type)Keys never coerce numerically.
    math::vec2 vec3 vec4the same type; the ivec of its dimensions (widens, as an int into a float)Another dimension, a color, a number.
    math::ivec2 ivec3the same typeThe vec of its dimensions: cast<math::ivec2>(v) truncates each component toward zero (a load error where both types are visible, the slot's error through a var). A constructor converts what it is handed: math::ivec2(v).
    class Cthe same class; a derived class (it keeps its class in the slot: B x = D(); type_of(x) is "D"); a shared_ptr to C or a derived class (copies the pointee); a value exactly one single-parameter constructor C(src) accepts directly; on plain =, a user operator= of C that accepts the sourceA parent, a sibling, an unrelated class of the same shape; arrays, maps, functions. null: a class value is never null (rule).
    shared_ptr<T>a handle to T or a subclass; a T value (construct-and-share); nullAnother pointee: shared_ptr<Bar> p = Foo() is a load error when the checker sees both classes, else Cannot initialize shared_ptr<Bar> with Foo: type must match or be a subclass.     weak_ptr<T>a handle to T or a subclass; nullAn instance: it has no shared owner.
    functiona function, a lambda, a bound method; nullAnything else, an instance with operator() included: wrap it in a lambda.
    T& (declaration or parameter)an lvalue that holds a T (a class: T or a subclass); a var only while it holds oneAny conversion: float& r = v with v holding an int raises Cannot initialize 'r' (declared float&) with int.
    T& parameter given a literal or temporarywhen its body never writes through it; a string& parameter takes one as a writable temporaryA write-through parameter: the load error 'bump' writes through parameter 'x' (line 1); pass a variable.
    a store through T&what the reference's declared type takes (var v = 0; int& r = v; r = 3.9 and r = "s" are load errors)What the storage's own declared type refuses: int x; var& w = x; w = 2.7 raises Cannot assign float to 'w' (declared int&).
    varanything, foreverNothing. Everything computed from a var is unknown to the checker and can only fail at run time.
    auto with an initializerthe initializer's type, then enforced as that typeA null initializer carries no type: the variable stays dynamic until its first non-null store.
    auto without an initializerdynamic until the first assignment, then lockedThe checker cannot see branch order and stays silent.
    CaseRule
    a op= b, typed or locked-auto targetComputes like C++ and converts back to the target's type: int i = 7; i /= 2 → 3; i += 0.5 and i += "s" are errors.
    a op= b, var targetStores whatever the operation produces.
    a op= b, missing map keyA compound reads its target first: map<string, int> m; m["x"] += 5 raises Key "x" not found in map.
    Value of an assignmentWhat the destination stored: float f; auto r = (f = 3) is float 3.0.
    Printing a floatThe shortest text that reads back to the same value, keeping .0 on a whole number; inf, -inf, nan (every NaN prints nan, under a format spec too).
    Format specsTemplate strings and {} placeholders take them: ${f:.1f} (format specs).

    The typed boundary​

    cast<T>(e), cast<T&>(e), cast<shared_ptr<T>>(e)​

    jaiscript
    class Base { int b = 1; }
class Derived : Base { int t = 0; }
class Holder { Base p = Derived(); }     // a Derived, held through a Base-typed field

print("{} {} {}", cast<int>('a'), cast<char>(97), cast<string>('z'));
char c = cast<char>(65);                 // `char c = 65;` would be a load error

auto h = Holder();
cast<Derived&>(h.p).t = 5;               // alias the same object: the store lands
print("{} {}", c, cast<Derived&>(h.p).t);

shared_ptr<Derived> sp = new Derived();
shared_ptr<Base> sb = cast<shared_ptr<Base>>(sp);   // share it, don't copy it
sb.b = 42;
print("{}", sp.b);

var v = Base();
try { Derived d = cast<Derived>(v); } catch (e) { print("caught: {}", e); }
    output
    97 a z
A 5
42
caught: Cannot cast 'Base' to 'Derived'
    FormYieldsRule
    cast<T>(e), class Twhat T tmp = e; would holdA value copy when e's class is T or derives from it; the copy keeps e's class. On a handle or a reference it copies the instance: the checker warns and suggests the two forms below.
    cast<T>(e), primitive Tthe conversion table's resultPlus float to int, truncating toward zero (cast<int>(2.7) is 2), and an int to the enum value it equals.
    cast<T&>(e)a reference to the same objectMember reads and stores go through: cast<Derived&>(h.p).t = 5 reaches a subtype's member through a base-typed receiver.
    cast<T&>(e) as a targetan lvalueIts declared type governs the store: cast<int&>(x) += 2 leaves an int in x, even when x is a var.
    cast<E>(n), enum Ethe enum value that equals nCannot cast 3 to 'E': not one of its values otherwise.
    cast<shared_ptr<T>>(e)a handle sharing the instanceAn upcast of a handle without a copy.
    cast<int>(c) / cast<float>(c)the code point, 0..255The char → int door.
    cast<string>(e)e's display text, as to_string(e) gives itThe explicit stringify; a char is its one-character string.
    cast<char>(e)a charFrom an int in 0..255 or a string of exactly one character; anything else raises Cannot cast 'int' to 'char' / Cannot cast 'string' to 'char'.
    a class mismatchthe catchable Cannot cast 'X' to 'T'X is the object's run-time class. The operand is never checked against T statically.
    nullan empty handle from the handle formFails the value form (Cannot cast 'null' to 'T') and the reference form (Cannot cast 'null' to 'T&').
    a T that names no typea load errorunknown type in cast: 'Nope'.

    Chapter: The Type Ladder.

    extern, inline, using​

    SpellingRule
    externDeclares a name that exists outside the program (a host global bound after load, a function the running instance registers, a value another engine injects). The checker counts it as declared instead of reporting use of undeclared identifier.
    extern at run timeDeclares nothing; the name resolves when used. A use while nothing defines it raises 'name' is declared extern but never defined (an 'inline' declaration creates it) (extern function: without the parenthesis).
    extern function log_to_host;A callable of unknown signature: calls are unchecked.
    extern int frame; / extern shared_ptr<Game> G;Typed: member access, assignments and conversions are checked as for a declared variable of that type.
    extern config;Untyped: behaves like var.
    extern function game::spawn; / extern int a::b::depth;A namespace member, in any of the three strengths. The namespace declares it (game::spawn is not no member 'spawn' in namespace 'game'), and the path opens the namespace for its other members' checks.
    Where it standsAt program scope or in a namespace, where its name is the namespace's: namespace game { extern int tick; } declares game::tick (read as tick by the namespace's own blocks); namespace game { extern ai::depth; } declares game::ai::depth.
    A qualified extern nothing definesRaises the same text with the qualified name: 'game::tick' is declared extern but never defined (an 'inline' declaration creates it). The definition is a namespace block of any unit (namespace game { int tick = 0; }) or the host's registration of that namespace.
    ReachAn extern name travels with the program: every unit the root imports sees it. Where a program does import the defining module, the declaration is inert and the definition wins.
    inline T name;The C++17 inline variable: one variable shared by every unit that declares it. The first unit to run creates it with its initializer or its type's default; the rest adopt it and their initializers do not run.
    A plain declaration of an inline variableRaises 'x' is already defined inline; declare it 'inline int x;' to share it; at load, with this text, when the checker sees both units.
    An inline declaration of another unit's plain variableRaises 'x' is already defined (not inline) in <file>; declare every definition 'inline' to share it.
    using ns::name;The rest of the file reads name as ns::name, for any namespace; a comma list works (using game::spawn, game::cost;). A parse-time rewrite: file-local, not transitive through imports or includes, and the name cannot be declared again in that file. There is no using namespace.

    [[warn_mode]] and [[strict_mode]]​

    jaiscript
    extern function log_to_host;   // the host registers this later: calls are unchecked
extern int frame;              // typed: reads and stores are checked as an int
extern config;                 // untyped: behaves like var

int total = 0;
try {
    [[warn_mode]] total = "oops";        // this one statement is only warned about...
} catch (e) {
    print("run time: {}", e);            // ...so the mistake surfaces here instead
}
print("{}", total);
    output
    run time: Cannot assign string to 'total' (declared int)
0

    The two attributes set the checker's mode for a region of one file. They compose and the innermost wins; everywhere else a file is strict.

    PositionCovers
    First declaration of a file ([[warn_mode]]; at the top; a leading comment is fine)The whole unit.
    First statement of a block (a function, method or lambda body, an if/while/for body, a bare { })The whole block, nested bodies included.
    Before any other statementThat statement's own subtree; a nested function or lambda body inside it keeps the enclosing mode.
    ModeRule
    Warn regionEvery error is reported as a warning (still collected, still visible through engine->check()). An undeclared identifier is accepted as unknown; nothing is proven from it.
    Strict regionErrors gate the load, even inside a warn region.
    Run timeNever changes: both backends treat the attribute as nothing, so a warn region's type mistakes raise at run time.
    ImportsA unit's mode says nothing about the units it imports.
    [[nodiscard]]Marks a function or a method whose result a caller must use (Functions). Any other attribute name is a parse error.

    Language rules in one place​

    The contractual one-liners: both backends are tested to agree on each, byte for byte.

    include vs import​

    Chapter: Modules.

    include "f.jai"import "f.jai"
    RunsEvery time it is evaluated.When first reached, then again when its file changed (checked in passes: import_recheck_interval, default 0.2 s).
    ScopeExecutes in the current scope.Module declaration.
    Expression?Yes: var cfg = include "config.jai"; evaluates to the file's last expression.The statement form never (auto x = import ... is a parse error). The call form import("f.jai") is a bool: true when a module ran.
    Dynamic pathsinclude(expr)import(expr)
    Checked how?A literal path joins the program closure: its names and classes are known to every unit and checked before anything runs. A dynamic path cannot be gathered: that unit's undeclared identifiers drop to warnings.
    IdiomForcing a re-run: hot reload of rules or content mid-game.Declaring the module graph at the top of each file.
    Persistent stateGoes in a module that is only imported and never included, so a reload cannot wipe it.
