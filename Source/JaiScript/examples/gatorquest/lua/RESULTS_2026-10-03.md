# Gator Quest smoke: JaiScript against Lua, LuaJIT and Luau, 2026-10-03

The smoke simulation of `gatorquest.jai -- smoke` as of the Raccoon Bandit change (the bandits live in the Raccoon
Warrens below the sewers), on five runtimes: the JaiScript VM, Lua 5.4.8 and 5.5.1, LuaJIT 2.1 and Luau 0.741. The
STATE_HASH values of `RESULTS_2026-10-02.md` describe the simulation before that change; this file supersedes them.

## Builds

- JaiScript: the Release runner (`jaiscript`, MSVC 19.51, /O2 /GL, /LTCG), master 8c71cc620 plus the Gator Quest
  scripts of this change; `--no-debug`.
- Lua 5.4.8, 5.5.1 and LuaJIT 2.1 (24c20c94): the binaries of `RESULTS_2026-10-02.md`.
- Luau 0.741 (tag `0.741`, 2d88f9b, released 2026-10-02): CMake + Ninja, `CMAKE_BUILD_TYPE=Release`,
  `LUAU_STATIC_CRT=ON`, MSVC 19.51.36252 x64 (/O2 /Ob2 /MT /DNDEBUG); target `Luau.Repl.CLI` (`luau.exe`), its
  conformance suite (`Luau.Conformance`) 317 of 317. Three configurations: the interpreter at the CLI's default
  optimization level (-O1), the interpreter at -O2, and native code (`-O2 --codegen`, which compiles the functions the
  code generator deems profitable; `--codegen-cold` would compile every function).

## The Luau program

`luau/gatorquest.luau` is generated by `to_luau.py` from the Lua 5.4 sources: the `luau` CLI runs each required
module in its own sandboxed globals, so the bundle runs every module as a function in one environment and assigns
its exports to the globals. Operators Luau lacks become `bit32` calls (`//` stays), and `luau/gq_util.lua` is the
hand-written util twin (Luau numbers are doubles: the 32-bit hash and RNG multiply exactly through `mul32`, as in the
LuaJIT twin, with `bit32` in place of `bit`). Generation keeps the three variants in step with one source; the util
module is the only hand-maintained file per variant. Run it as `luau [-O2] [--codegen] luau/gatorquest.luau -a smoke
ticks N seed S bots K`.

On this workload Luau's interpreter takes 0.74 to 1.03 times Lua 5.4.8's CPU time (-O2 gains nothing over -O1),
its native code 48 to 62% of its interpreter's, and LuaJIT's trace JIT is 2.7 to 3.6 times faster than Luau's native
code. The VM takes 4.4 to 5.8 times Luau's interpreter and 7.2 to 10.2 times Luau's native code (medians). Luau's
0-tick run (startup, compiling the 7000-line bundle, world generation) costs ~0.17 CPU s against Lua's 0.08.
