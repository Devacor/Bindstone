## 0. Mission and non-negotiable invariants

Shrink `jai::script_value` from 56 bytes to 32 bytes in two independently-green rungs:
- **Rung 1 (56 → 40):** fold the `cpp_bound_ptr_` + `cpp_bound_type_size_` side-members into the storage variant.
- **Rung 2 (40 → 32):** single-pointer `strong_ptr`/`weaker_ptr` (control block derived at a fixed negative offset) + box the dead `std::shared_ptr<script_value>` alternative; variant becomes 8B payload + index = 16B.

Final gate: `static_assert(sizeof(script_value) == 32)`.

Invariants that must hold at every commit:
- NO non-const statics/thread_locals.
- Every script_value carries an `engine*`; `engine_` and `type_info_` members STAY (they are the language: multi-engine zero-statics + the var/auto/int type ladder).
- `operator==`/`operator<=>` stay mutually consistent and form a strict weak ordering (script_value is a `std::map` key; complex types order by held-pointer identity).
- Never read a moved-from script_value; moved-from must be observable as {null storage, `is_cpp_bound()==false`, `get_engine()==nullptr`}.
- Both backends (interpreter + VM) share value.hpp; the full suite (~1390+, moving — 1394 at snapshot, see §1) must be green on BOTH backends after each rung.
- Zero source changes outside Source/JaiScript (recon-verified: MV/Game/Editor touch only the public API) — external cost is rebuild only.

## 2. Design decisions (conflict resolutions)

| # | Decision | Rationale (one line each) |
|---|---|---|
| D1 | Rung-1 cpp_bound representation = **boxed `strong_ptr<cpp_bound_holder>`** appended as variant alternative 14 (not an inline `{void*,uint8}` slot) | The holder carries {ptr, size_and_sign, semantic_index} unchanged through both rungs (16B strong_ptr in rung 1 → 8B in rung 2), so rung 2 never re-touches cpp_bound semantics and the meta byte never needs relocating; the one extra allocation lands only on cold `add_global_ref`/`make_value(T*)` setup paths. |
| D2 | **Append, never renumber**: TYPEID_CPP_BOUND = 14; dead alternative 11 is **boxed in place** (`strong_ptr<shared_value_holder>`), not removed | Indices 0-13 stay stable so all 515 TYPEID tokens, the 3 redundant copies of the ordering contract (storage_index enum, bare-literal current_type(), interpreter.cpp:2704 literal switch), and all 21 `get_if<TYPEID_*>` template args survive with only additive `case 14:` edits — the desync-prone bare-literal switches are never rewritten. |
| D3 | Registered-class T& bindings **stay on alternative 8**; `object_holder` gains `void* bound_ptr = nullptr` | They carry live type_name/type_id/keep_alive that a pointer-sized alternative cannot represent (all three designs agree); `is_cpp_bound()` becomes two-shape. |
| D4 | `raw_storage_index()` stays PURE (bound values report 14); the **`is_null/is_int/is_float/is_string/is_char/is_bool` family TRANSLATES** via the holder's `semantic_index` (Design 3 over Design 1's pure-index G1) | Verified counter-example to pure-index: `to_numeric` (detail/interpreter.hpp:901) gates on `is_int()` then decodes — pure-index would silently break unary numeric ops on bound ints; translation preserves today's answers at the numerous read sites and concentrates the audit on the small greppable write/get set whose failure mode is a LOUD Debug crash (null get_if / bad_variant_access), not a silent misroute. | D5 | The unavoidable **behavior deltas are adopted as bug fixes** (compound/incdec write-through; live bound-string compare/truthiness) and pinned by new tests; the unregistered-class null-ness observable is **preserved** via `semantic_index = TYPEID_NULL` | Bug-for-bug preservation is impossible once the dead shadow is gone (all three designs agree); preserving opaque-bound null-ness via semantic_index removes one Dev ruling entirely. ## 5. Semantic ground rules (rung 1)

- **S1:** `raw_storage_index()` stays a pure `storage_.index()` read. Bound primitives report 14. Consequence: every existing fast path gated `raw_storage_index() == TYPEID_INT/FLOAT/STRING` excludes bound values FOR FREE (verified: interpreter compound ultra-fast paths 3641/3685, VM cfor 3267/3283, param-bind 7769, string-concat index guards).
- **S2:** `is_null/is_int/is_float/is_string/is_char/is_bool` translate **on the deref'd value** — the whole family is deref-first today (value.hpp:268-282), and references/by-ref captures to bound globals must keep answering through the target. Exact prescribed shape (deref exactly once, then BOTH the index test and the box lookup on the deref'd value):
  ```cpp
  bool is_int() const {
  ```

## 12. Behavior deltas requiring Dev sign-off (the ONLY user-visible changes)

Bug-for-bug preservation is impossible once the dead shadow is gone. All deltas are latent-bug FIXES confined to `add_global_ref`/`make_value(T*)` bound values; none can break an existing green test (only `counter = counter + 50` is pinned today):
1. `boundInt += n`, `boundInt++/--`, `boundFloat += x`, `boundString += s`: today a complete silent no-op (mutates a write-only dead shadow; the C++ variable AND all reads are unchanged). After: real write-through. 
2. `boundString == x`, ordering (`< <= > >= <=>`), truthiness, concat reads: today compare/read the EMPTY shadow; after: the live C++ string (consistent with checked_as_string, which already decodes).
3. `boundInt += 2.5`: today silently replaces the value and drops the binding; after: converts and writes through via assign_through (binding kept).
4. **Non-const by-ref C++ extraction from a bound argument** (§12.4 — `engine.add_function` with `script_int&`/`std::string&` params via function_binder.hpp:290/:294, and non-const `as<T&>`): today the callee silently aliases the DEAD SHADOW — it reads 0/empty and its writes vanish. Converting silent-wrong into defined behavior is a sanctioned improvement, but it IS a delta and is stated as one: code that "worked" by accident against the dead shadow changes observably, and mismatched-width arguments go from silent-wrong to throwing. NEEDS DEV RULING (D12; fallback ruling — throw for ALL bound targets — touches the same four accessor branches).
5. **RULED PRESERVED (§12.5 — a ruling, not a delta; pinned so it cannot drift during implementation):** compound assignment and ++/-- on a bound value stored AS a container element / map value / object member / class field keeps today's semantics — decode-READ the live C++ value, compute, then DETACH-AND-REPLACE the element/member with the plain result (that slot's binding is dropped; the C++ variable is untouched). NOT write-through. The asymmetry with delta 1 is deliberate: a bound VARIABLE (env slot) has an assign_through target and its compound is a silent no-op today (broken either way → fixed to write-through), whereas element/member compound is green and observable today, and S8 normalization + the existing store-back reproduce it exactly (§7.16a/§7.17/§7.20a/§7.23b/§7.24a). Preserved (NOT deltas): unregistered-class bound null-ness (semantic_index=TYPEID_NULL), opaque-bound falsiness in is_truthy (BOTH copies — interpreter §7.13 and VM §7.15), opaque-bound operands through arithmetic/ordering still raise the same type_mismatch (S8 normalizes them to a monostate temp = today's index-0 behavior), bound-primitive READS through all arithmetic/ordering operators and unary `-`/`~` (S8 + §7.15a/§7.23a — incl. through refs/by-ref captures per S2), same_as answers on bound ints and aliases (§7.15b/§7.24b), opaque-bound map-key equivalence class, clone detach semantics, copy aliasing, keep_alive pinning, overload dispatch.
