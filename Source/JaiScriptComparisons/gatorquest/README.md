# Gator Quest: the Lua twin

The Lua side of the Gator Quest comparison: the game itself is `JaiScript/examples/gatorquest`.

`lua/` is a port of what the smoke session runs (world generation, the content tables, mobiles, spawners,
combat, items, quests, actions, bots, the tick and the state hash) to Lua 5.4+, one module per `.jai` file, with
generated LuaJIT and Luau twins. It
prints the same output as the JaiScript smoke run with `noroundtrip`, STATE_HASH included (`python lua/parity.py`
checks a seed/ticks/bots matrix line for line). Rendering, audio, netplay and save/load are not ported.

```
lua lua/gatorquest.lua smoke ticks 2000 seed 1 bots 2 [verbose]           # Lua 5.4 / 5.5
luajit lua/luajit/gatorquest.lua smoke ticks 2000 seed 1 bots 2            # LuaJIT (add -joff for its interpreter)
luau lua/luau/gatorquest.luau -a smoke ticks 2000 seed 1 bots 2             # Luau (-O2 before the file: its optimizer; -O2 --codegen: native code)
python lua/parity.py --jai PATH/jaiscript.exe --lua PATH/lua.exe --luajit PATH/luajit.exe --luau PATH/luau.exe
python lua/to_luajit.py                                                    # regenerate lua/luajit/ after editing lua/
python lua/to_luau.py                                                      # regenerate lua/luau/gatorquest.luau after editing lua/
```

Arrays stay 0-based, so every id, index and hashed value is the script's. Integer division and remainder
that can see a negative operand go through `idiv`/`imod` (C truncation); the script's
value-class copies are explicit (`copy_item`) wherever the copy is stored or mutated. `lua/luajit/` is generated
from `lua/` by `to_luajit.py` (operators to `bit` calls and `math.floor`); its `gq_util.lua` is hand-written,
because the 32-bit hash and RNG need exact 32-bit multiplies on doubles. `lua/luau/gatorquest.luau` is generated by
`to_luau.py` as one file: the `luau` CLI runs each required module in its own sandboxed globals, so the bundle runs
every module as a function in one environment and assigns its exports to the globals; operators become `bit32` calls
(`//` stays, Luau has it), and `luau/gq_util.lua` is the hand-written twin of the util module.
